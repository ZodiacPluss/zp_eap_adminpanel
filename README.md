# ZodiacPluss Admin Panel

The ZodiacPluss Admin Panel is a Vite-powered React dashboard for managing operations, clients, experts, finance, support, and settings.

## Quick Start

Requirements: Node.js 18+ and npm.

From this directory:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the Vite development server with hot reload |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build locally |

Vite updates the browser through hot module replacement while the development server is running.

## Project Structure

- `src/app/pages/` - dashboard screens and workflows
- `src/app/components/` - shared layout and UI components
- `src/app/data/` - design tokens and mock data
- `src/styles/` - global styles and theme definitions

## Development

Run `npm run build` before publishing changes to catch production-only issues.
